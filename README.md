# Профком студентів — React-версія

React-компонент з тією ж поведінкою, що і в опублікованій сторінці:
- наведення на лого блюрить увесь фон і показує бокс "Про нас" (Lorem Ipsum) збоку;
- 5 швидких кліків на лого 2 відкриває секретну гру в аерохокей, де граєш самими логотипами;
- режими "з другом" (мультитач, кожен керує своєю половиною) і "проти бота";
- рахунок і стрілочка "назад" у хедері.

## Структура

```
src/
  App.jsx        — весь UI та логіка гри
  App.css        — стилі
  assets/
    logo1.png    — лого профкому студентів
    logo2.png    — лого відділу з цифровізації
  main.jsx       — точка входу
index.html
package.json
vite.config.js
```

## Запуск

Потрібен Node.js 18+.

```bash
npm install
npm run dev
```

Відкриється на http://localhost:5173

## Збірка для продакшену

```bash
npm run build
```

Готові файли будуть у теці `dist/`.

## Якщо у вас вже є свій React-проєкт

Просто скопіюйте `src/App.jsx`, `src/App.css` і `src/assets/*` у свій проєкт
і підключіть `<App />` там, де потрібно.
